# Data

`data/test/` holds a small **synthetic** dataset (random numbers, no biological meaning) that is generated by
`python scripts/make_test_data.py` and is only used for tests/CI.

## Using real, public data

Put two files in `data/raw/` (they are git-ignored; do not commit data you are not allowed to redistribute):

| File | Format |
|---|---|
| `expression.csv` | genes x samples; first column = gene identifier; header = sample ids. Raw counts or log-scale values both work (counts are log2-transformed automatically). |
| `metadata.csv` | one row per sample with columns `sample_id`, the label column (e.g. `subgroup`) and, optionally, `os_time` and `os_event` (1 = event, 0 = censored). |

Then adapt `config/config.yaml` (column names, number of genes) and run `snakemake --cores 4`.

### Where to find suitable public data
- **GEO** (https://www.ncbi.nlm.nih.gov/geo/): search for a paediatric tumour cohort with subgroup labels and,
  ideally, survival. Array data need a probe-to-gene mapping before use; RNA-seq gene-level matrices are easier.
- **TARGET (e.g. neuroblastoma) via GDC / UCSC Xena**: open-access gene-level expression plus clinical outcome tables.

Always check the dataset's licence/terms and use only de-identified, openly available data. Verify accession
numbers on the source site yourself and cite the original publication in your README.
